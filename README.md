# 🇮🇳 India National Flag

A beginner-friendly Indian National Flag created using HTML with embedded CSS in a single file.

## Features
- Indian National Flag design
- Ashoka Chakra at the center
- Pure HTML and CSS
- Beginner-friendly
- Single-file implementation

## Technologies Used
- HTML5
- CSS3 (embedded in the HTML file)

## Project Structure
```
India-National-Flag/
│── index.html
└── README.md
```

## How to Run
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.

## Notes
- This project is created for educational and learning purposes.
- All HTML and CSS are contained in a single `index.html` file.
